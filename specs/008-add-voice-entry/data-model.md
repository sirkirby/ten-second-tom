# Data Model: Voice Entry with Local-First Speech-to-Text

**Feature**: 008-add-voice-entry  
**Date**: 2025-10-20  
**Status**: Complete

## Overview

This document defines the domain entities, value objects, and data structures for the voice entry feature. The model supports both local (whisper.cpp) and remote (OpenAI) speech-to-text transcription with flexible configuration and storage patterns.

---

## Core Entities

### 1. AudioRecording

Represents a captured voice recording with metadata.

**Properties**:
- `Filename` (string, required): Base filename (e.g., `note-20251020-143000.wav`)
- `FilePath` (string, required): Full path to audio file
- `Duration` (TimeSpan, required): Recording duration in seconds
- `SampleRate` (int, required): Sample rate in Hz (default: 16000)
- `Channels` (int, required): Number of audio channels (default: 1 for mono)
- `Format` (AudioFormat enum, required): Audio format (WAV, MP3, etc.)
- `Encoding` (string, required): Audio encoding (e.g., "pcm_s16le")
- `RecordedAt` (DateTimeOffset, required): Timestamp when recording was created
- `FileSizeBytes` (long, required): Size of audio file in bytes

**Validation Rules**:
- `Duration` must be > 0.5 seconds
- `SampleRate` must be 16000 Hz for whisper.cpp compatibility
- `Channels` must be 1 (mono)
- `Format` must be WAV for whisper.cpp
- `FilePath` must exist and be readable

**State Transitions**:
- `Recording` → `Recorded` (user presses Enter)
- `Recorded` → `Transcribing` (sent to STT engine)
- `Recorded` → `Deleted` (if `Audio:KeepFiles` = false after successful transcription)

**Example**:
```csharp
var recording = new AudioRecording
{
    Filename = "note-20251020-143000.wav",
    FilePath = "/Users/chris/.memory/ten-second-tom/today/note-20251020-143000.wav",
    Duration = TimeSpan.FromSeconds(145.3),
    SampleRate = 16000,
    Channels = 1,
    Format = AudioFormat.Wav,
    Encoding = "pcm_s16le",
    RecordedAt = DateTimeOffset.UtcNow,
    FileSizeBytes = 4647680
};
```

### 2. TranscriptionResult

Represents the output of speech-to-text processing.

**Properties**:
- `AudioReference` (string, required): Reference to source audio file (path or ID)
- `TranscriptText` (string, required): Full transcript text
- `SttEngine` (SttEngine enum, required): Engine used (Local, OpenAI)
- `SttModel` (string, optional): Model identifier (e.g., "ggml-base.en", "whisper-1")
- `ConfidenceScore` (float?, optional): Confidence score if available (0.0-1.0)
- `ProcessingDuration` (TimeSpan, required): Time taken to transcribe
- `TranscribedAt` (DateTimeOffset, required): Timestamp when transcription completed
- `WordCount` (int, required): Number of words in transcript
- `Language` (string?, optional): Detected language (if available)

**Validation Rules**:
- `TranscriptText` must not be null or empty
- `ConfidenceScore` must be between 0.0 and 1.0 if provided
- `ProcessingDuration` must be > 0
- `WordCount` must be ≥ 0

**Derived Properties**:
- `IsEmpty`: Returns true if `WordCount` == 0
- `ProcessingSpeed`: Returns audio duration / processing duration ratio

**Example**:
```csharp
var transcription = new TranscriptionResult
{
    AudioReference = "/Users/chris/.memory/ten-second-tom/today/note-20251020-143000.wav",
    TranscriptText = "Today was a productive day. I finished the audio recording feature...",
    SttEngine = SttEngine.Local,
    SttModel = "ggml-base.en",
    ConfidenceScore = null, // Not available for whisper.cpp
    ProcessingDuration = TimeSpan.FromSeconds(8.5),
    TranscribedAt = DateTimeOffset.UtcNow,
    WordCount = 42,
    Language = "en"
};
```

### 3. VoiceNoteEntry

Extends the standard `DailyEntry` with voice-specific metadata (note-oriented, not note-specific).

**Inherits From**: `DailyEntry`

**Additional Properties**:
- `AudioFilename` (string, required): Name of audio file (e.g., "note-20251020-143000.wav")
- `AudioDuration` (TimeSpan, required): Duration of audio recording
- `TranscriptText` (string, required): Full transcript from STT
- `SttEngine` (SttEngine enum, required): STT engine used
- `SttModel` (string?, optional): Model identifier

**Inherited Properties**:
- `EntryId` (string): Unique identifier (e.g., "today-10-20-2025-1")
- `Command` (string): Command name ("today")
- `Timestamp` (DateTimeOffset): Entry creation timestamp
- `EntryNumber` (int): Entry number for the day
- `UserInput` (string): Contains transcript text for voice entries
- `LlmResponse` (string): Summary generated by LLM
- `Metadata` (MemoryEntryMetadata): Processing metadata
- `Summary` (DailySummary): Structured summary

**Validation Rules**:
- All `DailyEntry` validation rules apply
- `AudioFilename` must be a valid filename
- `AudioDuration` must match `AudioRecording.Duration`
- `TranscriptText` must match `UserInput` content

**Example**:
```csharp
var voiceNote = new VoiceNoteEntry
{
    EntryId = "today-10-20-2025-1",
    Command = "today",
    Timestamp = DateTimeOffset.UtcNow,
    EntryNumber = 1,
    UserInput = "Today was a productive day. I finished the audio recording feature...",
    AudioFilename = "note-20251020-143000.wav",
    AudioDuration = TimeSpan.FromSeconds(145.3),
    TranscriptText = "Today was a productive day. I finished the audio recording feature...",
    SttEngine = SttEngine.Local,
    SttModel = "ggml-base.en",
    LlmResponse = "## Summary\n\n...",
    Metadata = new MemoryEntryMetadata
    {
        LlmProvider = "OpenAI",
        LlmModel = "gpt-4",
        TokensUsed = 1250,
        ProcessingDuration = TimeSpan.FromSeconds(3.2),
        CustomTags = new Dictionary<string, string>
        {
            ["InputMethod"] = "Voice",
            ["AudioFile"] = "note-20251020-143000.wav",
            ["SttEngine"] = "Local"
        }
    },
    Summary = new DailySummary { /* ... */ }
};
```

### 4. StoredRecording

Represents an archived recording in the `recording/` directory for future processing.

**Properties**:
- `AudioFilePath` (string, required): Full path to audio file
- `TranscriptionFilePath` (string, required): Full path to transcription text file
- `RecordedAt` (DateTimeOffset, required): Original recording timestamp
- `Duration` (TimeSpan, required): Audio duration
- `FileSizeBytes` (long, required): Audio file size
- `TranscriptionWordCount` (int, required): Number of words in transcript
- `SttEngine` (SttEngine enum, required): Engine used for transcription
- `SttModel` (string?, optional): Model used

**Validation Rules**:
- Both `AudioFilePath` and `TranscriptionFilePath` must exist
- Files must be in the `recording/` subdirectory
- File naming must follow pattern: `recording-YYYYMMdd-HHmmss.*`

**Lifecycle**:
- Created by `tom record` command
- Persisted permanently (never auto-deleted)
- Can be reprocessed by future `tom transcribe` command
- Can be processed by future prompt-based commands

**Example**:
```csharp
var storedRecording = new StoredRecording
{
    AudioFilePath = "/Users/chris/.memory/ten-second-tom/recording/recording-20251020-150000.wav",
    TranscriptionFilePath = "/Users/chris/.memory/ten-second-tom/recording/recording-20251020-150000.txt",
    RecordedAt = DateTimeOffset.Parse("2025-10-20T15:00:00Z"),
    Duration = TimeSpan.FromSeconds(320.5),
    FileSizeBytes = 10255360,
    TranscriptionWordCount = 287,
    SttEngine = SttEngine.Local,
    SttModel = "ggml-base.en"
};
```

## Entity Relationships

```
AudioRecording (1) ──> (1) TranscriptionResult
    │
    └──> (0..1) VoiceNoteEntry
    │
    └──> (0..1) StoredRecording

TranscriptionResult (1) ──> (0..1) VoiceNoteEntry

VoiceNoteEntry (IS-A) DailyEntry
    │
    └──> (1) DailySummary (inherited)
    └──> (1) MemoryEntryMetadata (inherited)

StoredRecording (1) ──> (1) AudioRecording (conceptually)
                 └──> (1) TranscriptionResult (conceptually)
```

**Relationship Descriptions**:

1. **AudioRecording → TranscriptionResult**: One recording produces one transcription result
2. **AudioRecording → VoiceNoteEntry**: One recording may be used for a note entry (optional)
3. **AudioRecording → StoredRecording**: One recording may be stored for later processing (optional)
4. **TranscriptionResult → VoiceNoteEntry**: One transcription may be used for a note entry
5. **VoiceNoteEntry extends DailyEntry**: Voice notes are a specialized type of daily entry
6. **StoredRecording references AudioRecording and TranscriptionResult**: Stored recordings maintain both audio and transcript

## Migration & Backward Compatibility

### Reading Legacy Entries

Entries without voice metadata are treated as text entries:
- Missing `input-method` → assumed "text"
- Missing `audio-file` → no audio section rendered
- All existing entries remain valid

### Writing New Entries

Voice entries include new metadata fields:
- `input-method`: "voice"
- `audio-file`: filename
- `audio-duration`: seconds
- `stt-engine`: "Local" or "OpenAI"
- `stt-model`: model identifier

Text entries continue to work as before:
- No voice-specific fields
- `input-method`: "text" (optional, inferred if absent)
